# Tailwind Analytics Dashboard 📊

Proyecto de maquetación de dashboard analítico responsivo con **Tailwind CSS** y visualización de datos interactiva con **Chart.js**, desarrollado para el **Checkpoint 4: Frameworks de CSS** de **Hybridge Education**.

## 🚀 Características
- **Tailwind CSS v3 (Utility-First):** Maquetación estructurada mediante grid y flexbox con paleta balanceada de colores (`slate`, `blue`, `green`, `purple`).
- **4 Tarjetas de Métricas Estadísticas (KPIs):**
  - Total de Usuarios con badge porcentual de incremento.
  - Ingresos Totales acumulados.
  - Tasa de Conversión mensual.
  - Sesiones Activas en vivo.
- **2 Gráficas Interactivas con Chart.js:**
  - Gráfica de línea: Comparativa de usuarios 2024 vs 2023 con sombreado de área suave (`tension: 0.3`).
  - Gráfica de barras: Distribución de ingresos mensuales 2024.
- **Microinteracciones y Efectos:**
  - Sombras suaves en hover (`hover:shadow-md`).
  - Botones y filtros de acción interactivos.

## 🛠️ Tecnologías
- HTML5 Semántico
- Tailwind CSS
- Chart.js (v4)
